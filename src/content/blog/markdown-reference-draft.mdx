## Code snippets

Inline `const lorem = 'ipsum'` inside a sentence. Fenced block with language tag:

```typescript
type LoremIpsum = {
  dolor: string;
  sit: number;
  amet: boolean;
};

export function consectetur(input: LoremIpsum): string {
  if (!input.amet) {
    throw new Error('sed do eiusmod tempor');
  }

  return ${input.dolor} ${input.sit}`;
}
```

Shell example:

```bash
curl -s https://example.com/api/lorem | jq '.items[] | .ipsum'
```

Plain text layout:

```text
lorem/
├── dolor/
│   └── sit.txt
└── amet.md
```
