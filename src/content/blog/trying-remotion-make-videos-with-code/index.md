I've wanted to try Remotion for quite a while. The idea is simple: instead of creating videos manually in a video editor, you can use code to generate videos, animations, and dynamic content.

I wanted to provide an SVG or PNG logo, configure things like the animation speed, duration, resolution, FPS, colors, and fonts, and then render the result as an MP4.

Remotion makes this possible while keeping the actual rendering workflow relatively simple. The final tool runs as a local web app and lets me configure the logo, zoom, duration, FPS, background, fonts, and other properties before rendering the animation.
